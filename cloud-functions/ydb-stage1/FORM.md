# Сайт и общая база

- GitHub Pages: https://alekssskorolev.github.io/sk-parket-site/
- API: https://d5dbi82cmvjpt86kth9a.d8epmcec.apigw.yandexcloud.net
- Сборка Pages: `npm run build:pages`. `build:demo` — только старое локальное демо, не использовать для публикации облачного сайта.
- `web-cloud/` — исходники облачного клиента; `docs/` — воспроизводимая статическая сборка. Не импортировать demo-api.js на рабочем сайте.
- Цены берутся из опубликованной версии YDB при открытии и раз в минуту. Черновик посетителям недоступен.
- Публичные запросы не отправляют cookie администратора.
- Отправка проверяет имя, телефон, согласие, версию цен и считает стоимость на сервере. Фото пока отклоняются и скрыты в интерфейсе.
- UUID запроса + отпечаток нормализованных данных хранятся 7 дней. Заказ и ключ повтора сохраняются в одной serializable-транзакции. Повтор после сетевого сбоя возвращает тот же номер, а не создаёт вторую заявку.
- Ограничения по IP/общему потоку хранятся в YDB, а не в памяти отдельной функции.

## Приём реальных контактов пока выключен

Политика и согласие в репозитории пока являются заглушками. Нужны данные оператора и согласованные тексты. Ничего не подставлять от имени пользователя.

После замены документов и подтверждения владельца в workflow задаются: `LEADS_ENABLED=true`, `PRIVACY_OPERATOR_CONFIRMED=yes`, `CONSENT_VERSION=<версия опубликованного согласия>`. Без любого из трёх условий API отказывает в записи, а форма остаётся выключенной.

После включения проверить на вымышленных данных: отправка с сайта → запись в админке, повтор одной отправки → тот же номер, цена и согласие совпадают с опубликованными версиями. Telegram и фотографии включаются отдельно.
