- Пароль — в Lockbox, не в GitHub. Минимальная длина 14 символов.

Функция остаётся приватной. API Gateway вызывает её с IAM-авторизацией существующего skparket-deployer; пароль и сессии проверяет приложение.

Для смены пароля создайте новую версию Lockbox и обновите ссылку secrets в workflow на её ID и ключ. Значение пароля в GitHub не переносится.
