# SK Паркет: сайт и админка

Это первая серверная версия, проверенная локально. Публичного адреса пока нет.

## Как открыть

1. Нужен Node.js 24, затем: `npm run setup` — создать собственный пароль.
2. `npm start` — запустить сервер.
3. Сайт: http://localhost:3000/ ; админка: http://localhost:3000/admin .

HTML не открывается двойным щелчком: этому варианту нужен сервер. Подробная инструкция — в `README.md`.

## Что важно

- Изменения сохраняются в черновик; сайт меняется после предпросмотра и публикации.
- В архиве нет готового пароля, реальных заявок, базы данных или секретов.
- Цены, расход и запас в исходных данных — рабочие примеры, а не утверждённый прайс.
- До запуска нужны реальный телефон, проверенные цены и расход, политика и согласие, HTTPS, постоянный диск и бэкапы.
- Приём реальных заявок по умолчанию выключен. Не включайте его до оформления документов и проверки хостинга.
- Базовая защита реализована; полноценный аудит рабочего размещения ещё не выполнен.

## GitHub и размещение

GitHub Pages не подходит: требуется серверный хостинг для Node.js и постоянная база.

С согласия владельца репозиторий `alekssskorolev/sk-parket-site` сделан публичным для демонстрации на GitHub Pages. Загрузка кода в GitHub сама по себе не запускает сайт: требуется серверный хостинг.

`.env`, папку `data/` и бэкапы никогда не добавлять в репозиторий.

## GitHub Pages

Статическая демоверсия — в docs/. Демо-админка без пароля; изменения и тестовые заявки сохраняются только в текущем браузере, без общей базы. Для переноса настроек есть экспорт/импорт JSON. Серверная версия сохранена в public/ и server.mjs.
