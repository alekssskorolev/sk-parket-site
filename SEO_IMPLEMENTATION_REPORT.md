## Локально, в репозитории и на публичном сайте

- **Локально:** найдены исходники, обновлена рабочая копия, сохранены 16 исходных тел/заголовков в /workspace/seo-evidence/before/. Локальная браузерная проверка упёрлась в доверие к сертификату прокси; TLS-проверка не отключалась. Затем облачная среда стала недоступна.
- **Подготовка кода и сборки:** дальнейшие изменения выполнялись через GitHub-коннектор; фактические сборки, тесты, подготовка снимков публичного API и изображений — на GitHub runner. Локальная рабочая копия после отключения среды не синхронизирована с финальными коммитами.
- **Публикация:** отдельные PR в main → существующий GitHub Pages, без миграции и изменения DNS/редиректов.
- **Публичная проверка:** отдельные GET и Chromium после публикации; кандидатные browser routes явно отделены от публичных проверок. Реальные заявки не отправлялись. Успешная отправка формы проверена только через локальный перехват запроса и mock-ответ, включая CORS preflight.

Первое слияние P0 было отклонено автоматической проверкой из-за production-публикации, изменения теста и неполного браузерного baseline. После получения публичного и кандидатного браузерного доказательства повторная проверка разрешила merge. Блокировка не обходилась прямым push.

## Что осталось

1. GitHub Pages не поддерживает собственный серверный 301 /index.html; он остаётся 200 с canonical. .htaccess/nginx, JS-редирект и миграция не добавлялись.
2. Владелец предоставит классификацию восьми геометрических карточек и подтверждённые данные для 3–5 кейсов отдельно. Новые услуги, параметры объектов и подписи не сочинялись.
3. Search Console и Яндекс Вебмастер недоступны: sitemap не отправлялся в кабинеты, переобход не запрашивался, фактическая индексация и выбранный поисковиком canonical не проверены.
4. Метрика сохранена; доступов к отчётам/целям нет. Органические показы, клики и заявки до/после не сопоставлялись.
5. Нет полевого CrUX/INP и полного исследования семантики. Рост трафика, позиции, CWV и rich results не обещаются.
6. Статический снимок обновляется через scripts/refresh-public-content.mjs и последующую сборку/публикацию. Открытая JS-версия продолжает брать изменения из API. Для обновления снимка нужны существующие pinned-зависимости sharp: npm ci --prefix cloud-functions/ydb-stage1/function --ignore-scripts --no-audit --no-fund.
7. Кеширование оставлено штатному GitHub Pages; собственные immutable-заголовки не настраивались. Новые имена изображений зависят от содержимого.
