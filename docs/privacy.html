Политика конфиденциальности

Редакция: skparket-pd-v3. Документ описывает обработку данных при обращении через форму сайта SK Паркет: https://alekssskorolev.github.io/sk-parket-site/.

Индивидуальный предприниматель Королев Алексей Сергеевич, ИНН 781699104994, ОГРНИП 312784731800668. Адрес: 192239, г. Санкт-Петербург, ул. Будапештская, д. 63, к. 1.

По вопросам персональных данных, исправления сведений и отзыва согласия: skparket@bk.ru; телефон +7 911 798-23-06. В теме письма можно указать «Персональные данные».

2. Цель и состав данных

Цель — обработать обращение об укладке паркета, связаться с заявителем, обсудить объект, подготовить и согласовать предварительную смету и возможность выполнения работ.

  • Телефон для обратной связи — обязательное поле.
  • Имя и комментарий — добровольные поля. Не указывайте паспортные данные, сведения о здоровье, платёжные данные и другую информацию, не нужную для обращения.
  • Если к заявке приложен расчёт: площадь, выбранные материалы, рисунок, основание, комплектация и предварительная стоимость.
  • Для учёта обращения: идентификатор и время заявки, версия согласия, статус и служебная заметка оператора.

Фотографии через форму сейчас не принимаются. Рекламные рассылки и профилирование не предусмотрены.

3. Основания и действия с данными

Для обработки обращения используется отдельное добровольное согласие. Галочка в форме установлена заранее и может быть снята пользователем. Само её исходное состояние не считается фактом получения согласия. В единственной строке согласия рядом с галочкой указано: отправляя заявку, пользователь даёт согласие на обработку данных на условиях политики конфиденциальности. Строка содержит ссылки на отдельное согласие и Политику. Подтверждением служит отправка формы с отмеченной галочкой; версия согласия сохраняется с отправленной заявкой. Документ согласия размещён отдельно: согласие на обработку персональных данных.

Обработка включает сбор, запись, систематизацию, накопление, хранение, уточнение, извлечение, использование для ответа и подготовки сметы, предоставление доступа уполномоченным лицам оператора, блокирование, удаление и уничтожение. Она выполняется с использованием средств автоматизации и, при работе с обращением, без них. Данные не публикуются в открытом доступе.

Если по обращению заключается договор, необходимая для исполнения договора и соблюдения закона обработка проводится на соответствующих самостоятельных основаниях. Согласие на заявку не заменяет условия договора.

4. Хранение, доступ и инфраструктура

Сведения из формы передаются по HTTPS непосредственно в API в Yandex Cloud и сохраняются в YDB в регионе ru-central1 (Россия). Доступ к заявкам предоставляется оператору через защищённую админку; посетители сайта не могут читать заявки.

Yandex Cloud используется как поставщик облачной инфраструктуры. Условия привлечения поставщика и поручения обработки обеспечивает оператор. Для уведомления оператора о новых обращениях используется Telegram: в личный чат оператора отправляется только общее сообщение о новой заявке и ссылка на защищённую админку. Имя, телефон, комментарий, адрес объекта, смета и идентификатор заявки в Telegram не передаются. Идентификатор личного чата оператора хранится в YDB для доставки уведомлений; токен бота — в Yandex Lockbox. Очередь уведомлений хранится до доставки, но не более семи дней.

Публичные файлы сайта размещены на GitHub Pages. Значения формы не отправляются в GitHub и не сохраняются в его репозитории. При открытии сайта GitHub может получать сетевые технические сведения, включая IP-адрес и параметры запроса, согласно политике GitHub. Размещение публичного сайта на GitHub само по себе не означает, что вся инфраструктура сайта находится в России.

Для ограничения злоупотреблений API использует хеш IP-адреса в часовом счётчике; логическое время действия счётчика — один час, физическое удаление выполняет механизм TTL базы. Идентификатор защиты от повторной отправки, идентификатор заявки и хеш её содержимого хранятся семь дней, затем удаляются через TTL. Сырые IP-адреса в строку заявки не записываются. Поставщики инфраструктуры могут вести собственные технические журналы по условиям предоставления услуг.

5. Cookie и локальное хранение

Приложение не использует рекламные трекеры или аналитические cookie. Публичная форма не хранит заявки в localStorage. Админка использует защищённый HttpOnly cookie сессии на срок до восьми часов; он нужен только для авторизации администратора.

6. Срок обработки и удаление

Обращение обрабатывается до достижения указанной цели либо до отзыва согласия, если отсутствует иное законное основание. После завершения обсуждения без заключения договора оператор удаляет данные, не нужные для других законных целей, в срок не более 30 дней. После отзыва согласия данные удаляются в срок, установленный законом, если их сохранение не требуется на другом законном основании.

Удаление заявок выполняет оператор через админку: автоматическое удаление клиентских заявок по сроку в приложении не настроено. Оператор контролирует сроки и удаляет также сделанные им выгрузки. Срок хранения договорных и учётных документов определяется отдельно применимыми требованиями законодательства.

7. Права заявителя и обращения

Можно запросить информацию об обработке своих данных, потребовать уточнения, блокирования или удаления при наличии законных оснований, отозвать согласие, обратиться в Роскомнадзор или суд. Направьте обращение на skparket@bk.ru; телефон +7 911 798-23-06; укажите телефон, использованный в заявке, и суть запроса. Не присылайте копию паспорта без отдельного обоснованного запроса. При необходимости оператор уточнит сведения для идентификации заявителя и ответит в установленный законом срок.

8. Защита и изменения

Применяются разграничение доступа, проверка авторизации администратора, HTTPS, ограничение запросов и защита от повторной отправки. Ответственность за доступ сотрудников, пароли, договоры с поставщиками и организационные меры несёт оператор. Изменения политики публикуются на этой странице; при изменении согласия используется новая версия.
